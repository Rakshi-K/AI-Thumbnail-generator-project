# Thumblify – AI Thumbnail Generator

An AI-powered YouTube thumbnail generation and analysis platform designed to help content creators create attractive, professional, and engaging thumbnails.

## 🚀 Project Overview

Thumblify is an AI-powered web application that helps YouTube creators generate, customize, analyze, and optimize video thumbnails. It combines AI-based image generation with an interactive editing experience to improve thumbnail quality and viewer engagement.

## ✨ Features

- **AI Thumbnail Generation:** Generate creative thumbnails using AI.
- **Multiple Thumbnail Styles:** Create thumbnails for different content categories.
- **Image Upload:** Upload and use personal images in thumbnail designs.
- **Thumbnail Editor:** Customize text, images, positioning, and layouts.
- **AI Thumbnail Analyzer:** Analyze thumbnail quality.
- **AI Quality Score:** Evaluate thumbnail designs using an AI-based scoring system.
- **Thumbnail Management:** View and manage generated thumbnails.
- **User Authentication:** Secure user registration and login.
- **Dashboard & Analytics:** Track thumbnail generation and project activity.

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd Thumblify
```

### 2. Install dependencies

```bash
npm install
```

Install client and server dependencies if they have separate package files.

### 3. Configure environment variables

Create the required `.env` files based on your project configuration.

Add your own credentials for:
- MongoDB connection
- JWT authentication
- AI provider API keys
- Other required services

Never upload real API keys or passwords to GitHub.

### 4. Run the application

Use the development command configured in your `package.json`:

```bash
npm run dev
```
